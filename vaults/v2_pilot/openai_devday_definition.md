# OpenAI DevDay: OpenAI's First Developer Conference, 6 November 2023

OpenAI DevDay was OpenAI's first developer conference, held on 6 November 2023 — the last major company event before the "leadership chaos" surrounding the firing and swift return of CEO and co-founder Sam Altman, which TechCrunch says raised concerns about OpenAI's direction and opened the door for competitors. At DevDay, OpenAI announced a slew of updates to GPT: GPT-4 Turbo, described as a super-charged version of GPT-4, its latest language-writing model; a multimodal API; and a GPT store where users can create and monetize their own custom versions of GPT.
