# Gary Wang Testifies on Alameda's Hidden Privileges in FTX Code

Gary Wang, co-founder of both FTX and Alameda Research and a second college roommate of Sam Bankman-Fried, testified in Bankman-Fried's fraud trial, which The Verge reported on 2023-10-26. Wang took the stand after fellow engineer Adam Yedidia and, per The Verge, "sang like a canary" about the secret privileges he had created for Alameda inside the FTX code. As a co-founder of both the exchange and the trading firm, Wang was positioned to describe how that code favored Alameda. Wang, Nishad Singh, and Caroline Ellison are now felons.
