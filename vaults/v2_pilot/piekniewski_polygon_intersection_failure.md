# Piekniewski's 2023-12-06 X post: Gemini-based Bard still can't code a polygon-intersection function

On 2023-12-06, Filip Piekniewski (X handle @filippie509) posted that he had "Tried gemini based Bard, and well, it still can't write intersection of two polygons," describing it as a "rare relatively simple to express" function that "wasn't ever implemented in python, there is no stack overflow post, and all these models fail on it." TechCrunch quoted the post on 2023-12-07 in "Early impressions of Google's Gemini aren't great" as an example of Gemini Pro — the version then rolling out to Bard — struggling with basic coding functions, despite Google touting Gemini's "enhanced coding skills" in a briefing earlier that week.
