# DALL·E 3 Integration Brings Text and Image Generation into One ChatGPT Interface

Per TechCrunch's coverage dated 2023-09-28, OpenAI integrated the DALL·E 3 image model into ChatGPT, so users can generate both text and images directly inside ChatGPT rather than switching to a separate tool. The integration sits alongside two other changes described in the same report: OpenAI had recently connected ChatGPT to the internet for all users, while the more natural and fluent GPT-4 model remained largely exclusive to paying ChatGPT users. DALL·E 3 thus extends ChatGPT from a text-only chatbot into a combined text-and-image product within a single interface.
