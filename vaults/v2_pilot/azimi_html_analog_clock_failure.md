# Azimi's analog-clock test of Gemini Pro, 2023-12-07

On 2023-12-07 Mohsen Azimi (@mohsen____) posted on X his result from testing Gemini Pro in Google's Bard. He asked the model to make an analog clock using HTML, the same kind of example ChatGPT had produced for him. According to Azimi's report, Gemini Pro "can cite some code from Github but it's off by a few ms." The post was quoted by TechCrunch the same day among several examples of users voicing frustrations with Gemini Pro's coding performance.
