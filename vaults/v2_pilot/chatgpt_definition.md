# ChatGPT — OpenAI's text-generating AI chatbot

ChatGPT is OpenAI's text-generating AI chatbot. It began as a tool to hyper-charge productivity: users write essays and code by feeding it short text prompts, and it composes the prose in response. In TechCrunch's description of it on 2023-09-28, that prompting-and-generation pattern is the core capability that made the chatbot widely known.

From that start, ChatGPT grew into something used by more than 92% of Fortune 500 companies for more wide-ranging needs, and it reached 100 million weekly active users since its initial launch nearly a year before that writing. Its underlying latest language-writing model is GPT-4.
