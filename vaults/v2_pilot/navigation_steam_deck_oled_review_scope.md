# Steam Deck OLED review: Engadget 2023-11-09 section map

This Engadget review of Valve's Steam Deck OLED (published 2023-11-09, scored 89) covers: positioning as a mid-cycle refresh rather than a Steam Deck 2; the 7.4-inch HDR OLED screen replacing the 7-inch LCD; battery life claims; the die-shrunk custom AMD APU; size and ergonomics (11.7 x 4.5 x 2 inches); thumbsticks, touchscreen and trackpad haptics; and in-game battery tests using Hades.
