# Google kept the colour term, DuckDuckGo dropped it, in a "kids BMX bike green" search test

In a search-engine comparison published by The Age on 2023-10-22, the query "kids BMX bike green" was run across providers. Google "did pretty well" and DuckDuckGo "ignored the green part" — that is, DuckDuckGo dropped the colour attribute from the query while Google respected it, a measurable difference in how the two engines handle attribute terms.
