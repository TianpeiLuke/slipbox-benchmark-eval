# Steam Deck OLED's Die-Shrunk APU Means No New Work for Game Developers

Valve's Steam Deck OLED uses a die-shrunk version of the custom AMD APU from the original Steam Deck — same CPU and GPU, just more efficient, per Engadget's review of 2023-11-09. That choice carries a consequence beyond power draw: the device keeps the same performance targets as the original Steam Deck, so developers have no need to create games specifically for the new hardware. Software already tuned for the LCD model needs no rework, and the OLED's other upgrades cost it no compatibility.
