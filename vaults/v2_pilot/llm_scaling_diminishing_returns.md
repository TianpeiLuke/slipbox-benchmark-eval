# Diminishing Returns on LLM Parameter Counts Relative to Compute Cost

In "8 predictions for AI in 2024" (TechCrunch, published 2023-12-19), the author models a break in the assumption that large language models keep improving proportionally as more compute is added. The prediction is that 2024 will reveal diminishing returns on parameter counts "to the point where training a 500-billion-parameter model may technically produce better results, but the compute required to do so could provably be deployed more effectively." The relationship is thus treated as non-linear rather than monotonic in cost: a 500-billion-parameter model may post the better score while remaining the worse use of the same compute. The article places the break in 2024 and concedes the exact point is unpredictable, since frontier research there is still active.
