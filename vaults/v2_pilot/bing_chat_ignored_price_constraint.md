# Bing Chat ignored a stated $200 budget in a 2023 search test

In an October 2023 comparison test reported by The Age (2023-10-22), a search for "kids BMX bike green" in Bing Chat returned a comparison of a few different options that the tester judged too expensive; Google "did pretty well" on the same query and DuckDuckGo ignored the green part. Asked in follow-up, "any under $200?", Bing Chat replied with more options that were all over $300 — it did not honour the stated price constraint.
