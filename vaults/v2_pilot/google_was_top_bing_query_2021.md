# "Google" was the top Bing search query in 2021 as Windows users overrode defaults

In its October 22, 2023 article "Is Google Search better than the rest? And is that fair?", The Age reports Google's argument, cited by president of global affairs Kent Walker, that users override defaults: when people set up a Windows device for the first time, they frequently sidestep the Microsoft default, and "Google" was the number one search query on Bing in 2021, despite Microsoft making that very annoying to do.
