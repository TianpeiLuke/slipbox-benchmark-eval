# The Age's Oct 2023 Search Test Surfaced Google's Data Footprint as DuckDuckGo's Counterargument

In a head-to-head search engine test published by The Age on 2023-10-22, the reviewer noted that the testing process itself revealed how much data Google collects: not only searches, but anything said to a smart speaker and every search result or ad clicked. This broader data footprint counted as a point in DuckDuckGo's favour for some users, even though DuckDuckGo performed worse in the test and was harder to read. The reviewer added that Google's data collection lets it personalise more effectively across search, mobile widgets, and other services.
