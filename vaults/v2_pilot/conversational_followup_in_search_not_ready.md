# Chatbot follow-up questions in search were not usable in a 2023 test

Against the pitch that chatbot follow-up questions enrich search, a test published in The Age on 2023-10-22 finds the capability "not really there yet". Searching Bing for "kids BMX bike green", the author got options that were too expensive; asking Bing Chat "any under $200?" returned more options all over $300. The generative layer on Bing's newly graphic, AI-augmented layout adds interface, not usable answers.
