# TechCrunch Author's Six-Letter French Word Test Exposes Gemini Pro's Multilingual Weakness

On December 7, 2023, writing for TechCrunch, the author entered the prompt "Can you give me a 6-letters word in French?" into Bard, which by then was running Google's newly rolled-out Gemini Pro model. Gemini Pro answered with a seven-letter word instead of a five-letter one — missing the requested length either way. The author read that single failed test as lending some credence to wider reports of Gemini's poor multilingual performance, echoing an earlier X post from December 6, 2023 in which another user reported the model struggling with the same French word-length request.
