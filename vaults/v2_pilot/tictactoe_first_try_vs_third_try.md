# Tic Tac Toe comparison suggests GPT-4 still ahead of Gemini Pro (Dec 2023)

On December 6, 2023, a user posting on X (shared in TechCrunch's December 7, 2023 article "Early impressions of Google's Gemini aren't great") compared two chatbots on the same task: writing a Tic Tac Toe game. ChatGPT produced working code on the first try, while Bard running on Gemini Pro required three attempts, which the poster posted as two videos. His conclusion: "GPT 4 still greater than Gemini Pro." The comparison was one of several coding tests users posted after Gemini Pro reached Bard, alongside a failed polygon-intersection function in Python and an HTML analog clock.
