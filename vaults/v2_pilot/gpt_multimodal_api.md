# Multimodal API (OpenAI DevDay, November 6)

A multimodal API is a programmatic interface to a model that accepts and returns more than one modality — text plus another medium such as images — instead of a text-only endpoint, where a developer sends a written prompt and gets written output back. The term appears here as one of "a slew of updates coming to GPT" that OpenAI announced at OpenAI DevDay, its first developer conference, held November 6, alongside GPT-4 Turbo and a GPT store for custom, monetizable versions of GPT (TechCrunch, 2023-09-28).
