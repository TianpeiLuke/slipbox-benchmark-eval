# FTX indictment: code features let Alameda withdraw unlimited funds

The Verge reported on 2023-09-28 that FTX's superseding indictment, filed August 14th, states there were special features in FTX's code that "permitted Alameda to spend and withdraw unlimited amounts of money from FTX," created at Sam Bankman-Fried's direction. That effectively exempted Alameda Research, Bankman-Fried's crypto trading firm, from the kinds of risk management other customers faced. At the same time, the government alleges, "Bankman-Fried publicly and repeatedly asserted that Alameda did not have privileged access to FTX."
