# TechCrunch author's Bard replication yields a distinct set of false 2023 Oscar results

On 2023-12-07, a TechCrunch author re-asked Gemini Pro in Bard the same question about the 2023 Oscar winners that had already produced errors from another user, and received a different set of wrong answers. The model stated that "Navalny" won Best Documentary Feature rather than "All the Beauty and the Bloodshed," that "All Quiet on the Western Front" won Best International Film, that "Women Talking" won Best Adapted Screenplay, and that "Pinocchio" won Best Animated Feature Film. The author concluded: "That's a lot of mistakes."
