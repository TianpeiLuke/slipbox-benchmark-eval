# Google's Drummond Called Microsoft's Search Default Anticompetitive in 2005

In 2005, after Microsoft made Internet Explorer the default search engine, Google legal chief David Drummond wrote to Microsoft arguing that the default was anticompetitive, according to a TechCrunch report dated 2023-10-31 on the U.S. government's antitrust case against Google. Drummond's letter rested on a claim about user behavior: most end users "do not change defaults," so the engine picked at the outset keeps the searches.
