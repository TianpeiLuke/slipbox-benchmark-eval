# Google's Defense That Search Defaults Are Easy To Change

Google's answer to the DOJ's foreclosure theory attacks the premise that a default locks users in: being default was not determinative, because changing from Google Search to another provider is easy, so Google's position reflects user preference rather than the deals.

In court, John Schmidtlein referenced Apple's deals with Yahoo and Bing that make those services easy to find, and both he and Eddy Cue argued that switching search engines is so easy as to be a non-issue; Meagan Bellshaw briefly stepped up to rebut that notion, and that was it for Cue's testimony. On Google's blog, president of global affairs Kent Walker said the search product was the favourite of users, browsers and device makers simply because it was the best in the business: "People don't use Google because they have to, they use it because they want to," and "this lawsuit simply ignores how intensely competitive and dynamic the technology industry is today." Walker's supporting evidence is revealed preference when Google is not the default: when Mozilla made Yahoo! the default on Firefox, most users changed it to Google; and people setting up a Windows device frequently sidestep the Microsoft default — "Google" was the number one search query on Bing in 2021 — despite Microsoft making that very annoying to do. The Age's writer called this a compelling point, familiar to anyone who has dodged Microsoft's pleading while setting Chrome and Google as defaults on a new PC, but countered that all of these arguments ignore that Google and its competitors are not on an even playing field: the question remains why users prefer Google, and if the answer is that Google is simply better, the further question is whether that is down to its scale, longevity, ubiquity and all the user data it sucks up, which no other company could possibly match.
