# ChatGPT Web Browsing And Plugins

OpenAI formally launched an internet-browsing feature for ChatGPT, ending the chatbot's confinement to training data up to September 2021 — a launch that came some three weeks after the feature was re-introduced in beta following several months in hiatus.

The path there ran through plugins and a withdrawal. OpenAI first connected ChatGPT to the internet by launching plugins, extending the bot's functionality by granting it access to third-party knowledge sources and databases, including the web; plugins were available in alpha to ChatGPT users and developers on the waitlist, with OpenAI saying it would initially prioritize a small number of developers and premium ChatGPT Plus subscribers before rolling out larger-scale and API access. OpenAI then announced that ChatGPT Plus subscribers could use a feature in the app called Browsing, which allows ChatGPT to search Bing for answers; it is enabled from the New Features section of app settings by selecting "GPT-4" in the model switcher and choosing "Browse with Bing" from the drop-down list, and it is available on both the iOS and Android apps. That web browsing capability for Plus subscribers, offered in July, was taken away after users exploited it to get around paywalls.

OpenAI posted on Twitter/X on September 27, 2023 that "ChatGPT can now browse the internet to provide you with current and authoritative information, complete with direct links to sources. It is no longer limited to data before September 2021."
