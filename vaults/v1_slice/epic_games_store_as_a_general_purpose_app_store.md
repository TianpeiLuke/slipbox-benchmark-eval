# The Epic Games Store As A General-Purpose App Store

Asked whether a freely installable Epic store on Android would be only a game store or also an app store, Tim Sweeney rejected the premise of the label: "the Epic Games Store isn't a games store — it's the store operated by Epic Games," and Epic will host any app anybody wants, of any sort.

The discriminating feature is that the store already carries non-games today: the Brave web browser and a number of software creation tools including Unreal Engine, with more coming, including other creation tools and productivity tools. The boundary case Sweeney concedes is one of emphasis rather than scope: gaming is a market Epic is uniquely close to, so he expects Epic would likely be able to forge closer partnerships and opportunities in gaming — but the store will be open to everybody on Android as it is on PC. The question that prompted the answer contrasted Epic with Valve, which operates a store that could be both but has decided to focus exclusively on games.
