# ChatGPT's Original Productivity Use Case

TechCrunch reported on 2023-09-28 that ChatGPT is OpenAI's text-generating AI chatbot that "started as a tool to hyper-charge productivity through writing essays and code with short text prompts." The article explains that this foundational capability launched the platform to widespread adoption, eventually expanding beyond its original scope to serve more than 92% of Fortune 500 companies. ChatGPT's core function remains generating human-like text responses to user prompts, enabling users to compose various forms of written content efficiently.
