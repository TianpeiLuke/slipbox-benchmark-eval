# Publisher Lawsuit Claims Google's SGE Opt-Out Problem

TechCrunch reported on 2023-12-15 that publishers cannot block Google's Search Generative Experience (SGE) without also losing placement in ordinary search results. The lawsuit argues that SGE uses the same GoogleBot crawler feed as general search, creating an inseparable connection. "Publishers also can't block SGE because it uses the same web crawler as Google's general search service, GoogleBot," the complaint states. This technical constraint allegedly leaves publishers with no clean opt-out option while facing potential traffic losses, as SGE aims to discourage visits to publisher websites by keeping users within Google's ecosystem.
