# Google's Default Search Engine Model Justification

TechCrunch reported on 2023-10-31 that Google executives defend their default search engine payment model as a virtuous cycle where default placement generates more queries, increased query data improves search quality, and superior search performance justifies continued default payments. During antitrust trial testimony, Google CEO Sundar Pichai argued that "Google pays big bucks to be everywhere so that it can take in all the data and be the best search engine across different companies' devices." The company spent $26.3 billion in 2021 on default placements, with $18 billion going to Apple alone. This reinforcing relationship between payment, data collection, and quality improvement represents Google's legal defense rather than an independently verified market dynamic.
