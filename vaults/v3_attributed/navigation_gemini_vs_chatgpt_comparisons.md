# Gemini Pro vs ChatGPT/GPT-4 comparison points in TechCrunch review

TechCrunch reported on 2023-12-07 that Google's Gemini Pro showed weaker performance than ChatGPT/GPT-4 in three key areas: "ChatGPT, by contrast, gives a bullet-list summary with citations to news articles" for news summarization; Gemini Pro failed to create an HTML analog clock correctly, being "off by a few ms"; and for Tic Tac Toe implementation, "ChatGPT wrote the code on first try" while "Bard on 3 tries."
