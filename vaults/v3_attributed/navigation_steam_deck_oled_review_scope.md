# Steam Deck OLED Review Navigation Index

Engadget reported on 2023-11-09 that the Steam Deck OLED review covers "positioning, OLED panel, battery, die-shrunk APU, ergonomics and size, input surfaces, in-game battery and thermal tests, wireless." The review describes it as "a mid-cycle refresh from Valve" that improves upon the original Steam Deck with better screen quality, battery life, thumbsticks, haptics, and thermal performance while maintaining the same form factor. Key sections include the HDR OLED display with 7.4-inch screen, 30-50% better battery life, custom AMD APU efficiency improvements, and ergonomic assessments.
