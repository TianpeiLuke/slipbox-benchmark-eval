# Google was 2021's top Bing search query despite Microsoft's default preference

The Age reported on 2023-10-22 that "Google" was the number one search query on Bing in 2021. This occurred because people setting up new Windows devices frequently sidestepped Microsoft's default search engine despite the company making that process deliberately awkward. The observation supports Google's claim that users actively choose their service over defaults.
