# Gemini Pro's Coding Limitations Observed in Basic Function Implementation

TechCrunch reported on 2023-12-07 that Google's Gemini Pro AI model struggled with basic coding tasks despite claims of enhanced capabilities. Filip Piekniewski observed on X on 2023-12-06 that Gemini-based Bard "still can't write intersection of two polygons" in Python, describing it as "one of those rare relatively simple to express functions that wasn't ever implemented in python, there is no stack overflow post, and all these models fail on it." The observation highlighted that while Google promoted Gemini's improved coding skills, the model failed fundamental programming challenges that require logical reasoning rather than just information retrieval.
