# Gemini Pro's Public Debut Met with User Disappointment Despite Google's Claims

TechCrunch reported on 2023-12-07 that Google's newly launched Gemini Pro model fell short of the company's public claims about its capabilities. Users reported failures across multiple categories including fact lookup accuracy, translation abilities, news summarization, and code generation. The model incorrectly stated 2023 Oscar winners, struggled with basic French translation requests, avoided controversial news topics, and failed to generate correct code for simple programming tasks like creating a snake game or analog clock. "It seems Gemini Pro is loath to comment on potentially controversial news topics, instead telling users to... Google it themselves." Security researchers also found the model susceptible to jailbreaking attempts that bypassed safety filters.
