# Gemini Pro's French Word Length Error Supports Multilingual Performance Concerns

TechCrunch reported on 2023-12-07 that when the author prompted Gemini Pro through Bard to "give me a 6-letters word in French," the model responded with a seven-letter word instead. The author noted that this incorrect response "gives some credence to the reports about Gemini's poor multilingual performance." This empirical observation joins other documented failures including incorrect Oscar winners, struggles with news summarization, outdated information about the Ukraine war, and coding difficulties. The French word length error specifically demonstrates the model's inability to follow basic numerical constraints in language tasks.
