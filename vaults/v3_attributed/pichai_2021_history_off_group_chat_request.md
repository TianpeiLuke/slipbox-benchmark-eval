# Pichai requested chat history-off in 2021 personnel matter

TechCrunch reported on 2023-10-31 that during Sundar Pichai's antitrust testimony, DOJ lawyer Meagan Bellshaw displayed a 2021 exchange where Pichai asked for history to be turned off in a group chat. "Bellshaw pulled up a message exchange in 2021 where Pichai asked for history to be turned off in a group chat." Pichai testified this request concerned a personnel matter unrelated to the litigation hold, according to the report.
