# FTX Code Contained Special Features for Alameda's Unlimited Access

The Verge reported on 2023-09-28 that the indictment alleges FTX's code contained special features permitting Alameda Research to spend and withdraw unlimited amounts from FTX. These features were allegedly created at Sam Bankman-Fried's direction, effectively exempting Alameda from the risk controls applied to other customers. The government claims this occurred while Bankman-Fried publicly denied that Alameda had privileged access to FTX.
