# Default Search Engine as Scarce Distribution Asset

TechCrunch reported on 2023-10-31 that Google paid $26.3 billion in 2021 to device makers like Apple, Samsung, and Mozilla to become the default search engine on their platforms. A default search engine is "the query service preselected by a device or browser maker so that a user searches through it without taking any setup action, making the placement itself the scarce asset that distributors sell." The U.S. government's antitrust trial argues this practice blocks competition in search and advertising markets. Google defended these payments as necessary to collect data and maintain quality across different devices, with $18 billion alone going to Apple. Internal emails showed Google understood early on that homepage defaults significantly impact search volume, with users doing 15% more searches when defaulting to Google.
