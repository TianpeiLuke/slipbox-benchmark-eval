# Mozilla's Yahoo Default Change Shows Users Prefer Google

The Age reported on 2023-10-22 that when Mozilla made Yahoo the default search engine on Firefox, most users changed it back to Google. This empirical observation was cited by Google in its 2023 trial response as evidence that defaults do not determine user behavior, contradicting claims that Google's dominance stems from default settings rather than user preference.
