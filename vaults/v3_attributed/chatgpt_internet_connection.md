# OpenAI Connected ChatGPT to Live Internet for All Users in Late 2023

TechCrunch reported on 2023-09-28 that OpenAI recently connected ChatGPT to the internet for all users. This integration removed the model's knowledge cut-off as a barrier for free tier users, allowing access to current information beyond the previous training data limitations. The update was part of OpenAI's broader expansion efforts following its November 2023 developer conference where additional features like GPT-4 Turbo and DALL-E 3 integration were announced.
