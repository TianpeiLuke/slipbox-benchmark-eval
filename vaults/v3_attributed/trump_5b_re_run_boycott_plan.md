# SBF Allegedly Proposed $5B Payment to Trump to Withdraw from 2024 Election

TechCrunch reported on 2023-10-02 that Michael Lewis claimed Sam Bankman-Fried devised a plan to pay Donald Trump roughly $5 billion not to run again for president. "Like how much would it take to get an answer? There was a number that was kicking around… this was $5 billion," Lewis recounted in a 60 Minutes interview. However, Lewis stated that SBF was never sure whether that figure came directly from Trump personally, and there is no evidence any money was transferred — a fact the trial could establish.
