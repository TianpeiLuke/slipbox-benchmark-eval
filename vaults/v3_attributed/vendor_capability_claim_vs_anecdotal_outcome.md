# Google's Gemini Pro Falls Short of GPT-4 Parity Despite Marketing Claims

TechCrunch reported on 2023-12-07 that Google's Gemini Pro model, despite being marketed as meeting or exceeding GPT-4 performance, shows significant shortcomings in real-world usage. Users reported factual errors, poor multilingual performance, outdated information, and coding difficulties. One user noted Gemini Pro incorrectly stated Brendan Gleeson won Best Actor instead of Brendan Fraser. Another found it struggled with basic French translation requests. When asked to summarize news, Gemini Pro often avoided controversial topics or provided outdated information about the Ukraine war. Coding tasks also proved challenging, with users reporting failures in generating correct Python code for simple functions. Security researchers even bypassed safety filters to make Gemini Pro suggest harmful activities. These anecdotal failures contradict Google's benchmark-style marketing claims about Gemini's capabilities.
