# Gemini Pro's Analog Clock Implementation Error

TechCrunch reported on 2023-12-07 that Gemini Pro struggled with basic coding tasks. Mohsen Azimi demonstrated this by asking Gemini Pro to generate an HTML analog clock similar to one ChatGPT had created. While Gemini Pro could cite code from GitHub, "it's off by a few ms" according to Azimi's tweet. This error occurred despite Google's claims that Gemini's coding skills were enhanced, with the model failing to match even ChatGPT's performance on this straightforward JavaScript timing task.
