# Multimodal API announced at OpenAI DevDay

TechCrunch reported on 2023-09-28 that OpenAI announced a multimodal API at its first developer conference (DevDay) on November 6. The API represents a programmatic interface to GPT that handles more than one input/output modality, distinguishing it from text-only endpoints. This multimodal capability was part of several updates including GPT-4 Turbo and a GPT store for custom GPT creation and monetization.
