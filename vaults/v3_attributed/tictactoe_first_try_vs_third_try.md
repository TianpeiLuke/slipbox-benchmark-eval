# Gemini Pro struggles with basic coding tasks compared to ChatGPT

TechCrunch reported on 2023-12-07 that Gemini Pro showed inferior performance to ChatGPT on basic coding tasks. A user comparison found that "ChatGPT wrote the code on first try" for a Tic Tac Toe game, while "Bard on 3 tries" was required. Another user reported that ChatGPT 3.5 created a "correct bug-free" snake game code on first attempt, whereas Bard with Gemini Pro could not produce error-free code even after multiple attempts. These observations contradict Google's claims that Gemini meets or exceeds GPT-4 performance.
