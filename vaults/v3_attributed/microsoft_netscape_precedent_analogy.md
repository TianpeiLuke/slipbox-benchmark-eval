# Epic's Antitrust Case Against Google Relies on Microsoft Precedent

TechCrunch reported on 2023-11-06 that Epic Games' antitrust trial against Google relies on the precedent set by the Microsoft antitrust case, where courts found Microsoft had a monopoly over the operating system and was abusing it. "The precedent Epic's case will rely on is a Microsoft case where courts found Microsoft to have a monopoly over the operating system and were abusing it, making it hard for users to download alternative browsers, like Netscape, on Windows devices." Epic argues Google similarly restricts competition by making alternative app distribution methods difficult, particularly through restrictive agreements with device manufacturers and developers, mirroring how Microsoft made alternative browsers hard to install.
