# Google's Meaning Matching Process for Search Queries

The Age reported on 2023-10-22 that Google Search's meaning matching system "looks beyond the specific words in a query to better understand what someone is really looking for." This process handles misspellings, synonyms, and ambiguous phrasings by inferring user intent rather than matching keywords literally. Google's search liaison Danny Sullivan explained that this separate organic matching process is distinct from ad keyword matching, which connects people to relevant advertisements.
