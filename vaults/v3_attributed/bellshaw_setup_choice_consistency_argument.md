# Bellshaw's Counter-Argument on Apple's Setup-Minimalism Defense

The Verge reported on 2023-09-26 that Justice Department lawyer Meagan Bellshaw challenged Apple's argument that limiting user choices during iPhone setup is necessary for simplicity. During Eddy Cue's testimony in the US v. Google antitrust trial, Bellshaw pointed to three specific setup screenshots: the Appearance selection screen, Maps location tracking prompt, and App Tracking Transparency notification. "We try to get people up and running as fast as possible," Cue argued, claiming setup should only include "critical stuff." However, Bellshaw's counter-argument highlighted that Apple already requires users to make decisions about font size, appearance, location tracking, and app data collection during setup, suggesting that offering a choice of search engines could logically be included in this existing decision-making process rather than being fixed as Google by default.
