# Google vs DuckDuckGo Attribute Handling in BMX Bike Search

The Age reported on 2023-10-22 that in a search comparison for "kids BMX bike green," Google Search "did pretty well" while DuckDuckGo "ignored the green part." This demonstrates a measurable difference in how the two search engines handle color attributes in queries.
