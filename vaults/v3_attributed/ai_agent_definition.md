# AI Agents Defined as Tool-Access Systems

TechCrunch reported on 2023-12-19 that AI "agents" are systems granted access to external user tools and data such as spreadsheets, ticket-buying interfaces, and transportation apps, distinguishing them from simpler summarizers and list-making AI. The publication predicted these agents would show more convincing capabilities in 2024, particularly for tedious processes like insurance claims submission.
