# SEO-Optimized Content as Corporate Dictionary Entries

The Verge reported on 2023-11-01 that search engine optimization has degraded internet search results to the point where looking up "sneaker" in a dictionary would yield an entry "that sounds both incorrect and suspiciously as though it were written by someone promoting Nike ('footwear that allows you to just do it!')". This analogy illustrates how SEO-shaped results read as vendor-authored content rather than objective information, contributing to widespread user frustration with Google Search's declining quality and authenticity.
