# TechCrunch's ChatGPT Product Timeline and FAQ

TechCrunch reported on 2023-09-28 that it maintains "a timeline of ChatGPT product updates and releases, starting with the latest, which we've been updating throughout the year. And if you have any other questions, check out our ChatGPT FAQ here." The timeline features reverse-chronological updates including December 2023 developments such as reopened ChatGPT Plus subscriptions, partnerships with Axel Springer, judicial use in UK courts, and addressing user concerns about seasonal behavioral changes in the chatbot.
