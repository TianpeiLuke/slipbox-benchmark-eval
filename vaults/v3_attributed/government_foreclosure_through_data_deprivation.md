# Government's Antitrust Argument Against Google's Default Search Deals

TechCrunch reported on 2023-10-31 that the U.S. government argues Google's $26.3 billion spending on default search engine deals blocks competition by preventing rivals from accessing crucial query data. The government's theory of harm is that "Google uses its platforms and deals with partners to block out any competition in search or advertising, thus hindering competitors from accessing the data they'd need to improve their products." This strategy allegedly creates a monopoly by denying competitors the data necessary to develop better search engines, as demonstrated by Google's own internal recognition that homepage defaults significantly impact search volume. Microsoft's CEO testified that Bing could have been competitive if it had similar default placement opportunities.
