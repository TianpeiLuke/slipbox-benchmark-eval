# Live Odds Feed for Line Shopping

Sporting News reported on 2023-11-06 that a live odds feed aggregating multiple top US sportsbooks "is the easiest way to line-shop" because it allows bettors to compare lines and odds across books in seconds. The publication explains that sportsbooks set odds using computer models considering analytics, statistics, injury news, and matchup data, but lines vary between books due to different betting patterns and timing. This creates opportunities for bettors to find better prices by comparing the same bets across platforms. Manual comparison using multiple sportsbook apps is also effective but takes longer than using aggregated feeds.
