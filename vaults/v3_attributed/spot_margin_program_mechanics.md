# FTX Spot Margin Program Definition

The Verge reported on 2023-10-10 that the spot margin program was FTX's feature "let users lend each other assets for margin trading." This program was distinguished by permitting "a negative balance in a specific coin," though it did not allow accounts to avoid liquidation or maintain an overall negative balance.
