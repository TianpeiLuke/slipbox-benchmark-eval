# ChatGPT Integration with DALL-E 3 Enables Multimodal Content Generation

TechCrunch reported on 2023-09-28 that ChatGPT's integration with DALL-E 3 allows users to generate both text and images within the same interface. This multimodal capability was highlighted as part of OpenAI's broader expansion of ChatGPT's functionality, alongside other features like internet connectivity for all users and the introduction of GPT-4 Turbo. The integration represents OpenAI's effort to make ChatGPT a more versatile AI tool that can handle diverse content creation needs through a single platform.
