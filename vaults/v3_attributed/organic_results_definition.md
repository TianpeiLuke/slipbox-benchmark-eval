# Google's Definition of Organic Search Results

The Age reported on 2023-10-22 that Google defines "organic results" as the list of blue links returned for a query that are not sponsored placements. In response to allegations about search manipulation, Google's search liaison Danny Sullivan clarified that ad systems do not affect these organic results, which are generated through a separate process unrelated to advertising.
