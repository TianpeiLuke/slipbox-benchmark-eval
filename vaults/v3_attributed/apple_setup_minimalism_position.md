# Apple's Cue argues default search engine choice is about user experience, not revenue

The Verge reported on 2023-09-26 that Apple executive Eddy Cue defended the company's default search engine arrangement with Google during antitrust trial testimony, arguing that Apple chooses Google because it provides the best user experience rather than solely for the billions in annual payments. Cue specifically stated that during iPhone setup, "We try to get people up and running as fast as possible" and that "Setup is just critical stuff." He contended that presenting users with unfamiliar search engine options during first-time setup would create a poor experience, saying he couldn't even recall the names of alternative search engines. This argument was scoped specifically to the initial device setup process, distinct from later settings changes.
