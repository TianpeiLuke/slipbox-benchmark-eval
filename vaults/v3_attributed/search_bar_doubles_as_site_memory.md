# Google Search Switching Costs Revealed by Habit Dependency

The Age reported on 2023-10-22 that Google's dominance in search creates switching costs for users due to habit formation. The author observed that they use Google's search bar as much for returning to familiar sites as for looking up new information, making a switch to rival providers temporarily annoying since those alternatives lack the personalized destination data that Google has collected. This habitual usage pattern suggests that "switching to another provider could be temporarily annoying simply because it wouldn't remember all the places I've been."
