# Gemini Pro factual accuracy issues reported on social media

TechCrunch reported on 2023-12-07 that Google's Gemini Pro AI model, deployed in Bard, demonstrated significant factual inaccuracies when answering basic questions. Vitor de Lucca reported on X that Gemini Pro incorrectly identified Brendan Gleeson as the previous year's Best Actor Oscar winner instead of Brendan Fraser, calling the result "very, very bad" for a question answerable by retrieval. The model also provided multiple incorrect answers about other 2023 Oscar categories and struggled with basic French translation tasks.
