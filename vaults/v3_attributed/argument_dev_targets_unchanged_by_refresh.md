# Steam Deck OLED Maintains Original Performance Targets

Engadget reported on 2023-11-09 that the Steam Deck OLED uses a die-shrunk version of the original custom AMD APU, keeping the same CPU and GPU. "For developers, this means the device has the same performance targets as the original and there's no need to create games specifically for the new hardware."
