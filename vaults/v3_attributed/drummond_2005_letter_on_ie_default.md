# Google's 2005 Antitrust Concerns Over Default Search Engine Status

TechCrunch reported on 2023-10-31 that Google legal chief David Drummond wrote to Microsoft in 2005, arguing that making Internet Explorer the default search engine was anticompetitive. The letter stated that "most end users do not change defaults," highlighting Google's early understanding of how default settings could impact market competition. This concern preceded Google's own extensive payments to become the default search engine across platforms, including Apple devices.
