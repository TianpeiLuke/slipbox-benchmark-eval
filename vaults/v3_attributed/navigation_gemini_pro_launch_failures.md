# Gemini Pro failure reports index by task class, December 2023

TechCrunch reported on 2023-12-07 that users testing Gemini Pro in Bard encountered errors across multiple domains. Reported failures included factual inaccuracies like misidentifying 2023 Oscar winners, confabulation such as falsely claiming author Charlie Stross contributed to the Linux kernel, multilingual constraints demonstrated by failing to provide correct French six-letter words, outdated news summaries regarding the Ukraine war, and coding deficiencies including inability to generate functional Python code for polygon intersections. "It still give very, very bad results to questions that shouldn't be hard anymore."
