# Apple's Default Search Engine Definition in US v. Google Trial

The Verge reported on 2023-09-26 that Apple defines a default search engine as one that is automatically selected during device setup, requiring users to actively change it rather than choose from multiple options. During testimony in the US v. Google antitrust trial, Apple executive Eddy Cue defended the company's Information Services Agreement (ISA) with Google, stating "we make Google be the default search engine because we've always thought it was the best." Cue testified that Apple prioritizes getting users "up and running as fast as possible" during iPhone setup, which is why the ISA doesn't allow users to choose between search engines during the initial configuration process.
