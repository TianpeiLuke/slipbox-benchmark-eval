# Wang's testimony on FTX code privileges and Alameda's unlimited access

CNBC reported on 2023-10-06 that Gary Wang testified about special access code baked into FTX's platform that gave Alameda Research advantages including "unlimited withdrawals on the exchange." Wang stated that these privileges, which he oversaw as technology chief, enabled Alameda to withdraw and transfer customer-derived funds while he was employed at FTX.
