# Yedidia's Immunity Deal Explanation

Fortune reported on 2023-10-04 that Adam Yedidia testified about his immunity agreement, stating he was concerned he had "unwittingly written code that contributed to a crime." The testimony occurred during the Sam Bankman-Fried trial proceedings.
