# Generative AI follow-up questions in search engines lack practical utility

The Age reported on 2023-10-22 that while Bing has implemented chatbot-style follow-up questions in search, the feature "isn't really there yet" in terms of practical usefulness. The author tested this capability by asking follow-up questions like "any under $200?" after initial searches, but found the generative AI responses failed to provide relevant answers, instead offering options that didn't meet the specified criteria. This suggests that despite the appealing concept of conversational search, the current implementation adds interface complexity rather than meaningful functionality.
