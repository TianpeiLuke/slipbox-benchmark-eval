# OpenAI DevDay as First Developer Conference

TechCrunch reported on 2023-09-28 that OpenAI held its first developer conference, OpenAI DevDay, on November 6, 2023, immediately before the company's leadership crisis. "Prior to the leadership chaos, on November 6, OpenAI held its first developer conference: OpenAI DevDay." The conference announced updates including GPT-4 Turbo, a multimodal API, and a GPT store for users to create and monetize custom GPT versions.
