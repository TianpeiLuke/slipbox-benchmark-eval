# Google's Knowledge Panel Draws Content from Publisher Websites to Satisfy Search Queries

TechCrunch reported on 2023-12-15 that when users search for information on a topic, Google displays a "Knowledge Panel" to the right of the search results containing summaries drawn from the Knowledge Graph database. The complaint in a class action lawsuit filed by Helena World Chronicle states: "When a user searches for information on a topic, Google displays a 'Knowledge Panel' to the right of the search results. This panel contains a summary of content drawn from the Knowledge Graph database." Google compiled this database by extracting information from publishers' websites and other sources, allegedly misappropriating content to satisfy user queries without directing traffic to original publisher pages.
