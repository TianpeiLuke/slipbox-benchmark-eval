# Hikvision Ethnicity Detection And Protest Alarm Features

Hikvision has marketed facial-recognition features that would, it claimed, automatically detect Uyghur people, and it has also advertised features meant to discern any person's ethnicity, age and race based on an image of their face.

The company's marketing extended to protest detection as well. The Guardian first reported that Hikvision enabled police clients to set up alarms triggered when cameras detect any type of protest activity.

The categories named in that alarm marketing were "gathering crowds to disrupt order in public places," "unlawful assembly, procession, demonstration" and threats to "petition."
