# How Google Search Crawls, Indexes And Ranks Results

Google Search works as a chain of stages: software constantly crawls the web and updates a central index — itself more than 100 million gigabytes in size — and then, when a query arrives, Search uses a few quick processes to decide the meaning of the question, including what kind of information the user might be after, before ranking results.

Ranking goes beyond looking for sites containing the words typed in: the system uses machine learning to rank results according to what it thinks the user is looking for, prioritising high quality and easy-to-use sites. Personalisation is an optional further stage: if allowed, Google brings in some information it knows about the user to refine results, including location and web history, which can be turned off in Google account settings under "Web & App Activity"; Google says it does not infer personal information like race or religion to shape results. A feedback loop sits alongside the pipeline — Google works with independent "search quality raters" to gauge the effectiveness of its processes and says it ran almost 900,000 quality tests in 2022. The Age noted the contested reading of the meaning-matching stage: critics including Megan Grey contend that Google uses semantic keyword matching to make searches less precise on purpose, which widens the pool of content served and increases auctions for its ads, whereas the quality tests would be the mechanism ensuring the systems still return results justifiably related to the input.
