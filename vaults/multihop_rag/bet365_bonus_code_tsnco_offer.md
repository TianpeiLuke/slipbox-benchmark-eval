# Bet365 Bonus Code TSNCO Offer

Bet365 bonus code TSNCO gives new customers a choice between two promo offers — a First Bet Safety Net up to $1,000 or a Bet $5, Get $150 in bonus bets deal — as promoted by Sporting News on Nov. 29, 2023 for ACC-SEC Challenge games.

The First Bet Safety Net protects a new customer's initial wager up to $1,000. The alternative is the Bet $5, Get $150 in bonus bets offer. Both promos can be used to bet on any CBK games, including that night's ACC-SEC Challenge matchups.

The code varies by state: Bet365 bonus code VATSN applies in Virginia and NJTSN in New Jersey.
