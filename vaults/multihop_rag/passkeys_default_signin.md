# Passkeys As The Default Google Sign-In Method

A passkey is a phishing-resistant alternative to a password that lets users sign in to accounts using the same biometrics or PINs they already use to unlock their devices, or with a physical security key. As TechCrunch reported on 2023-10-13, Google is now making passkeys the default sign-in method for all users.

Two features discriminate a passkey from a password. First, resistance to phishing is the property the definition leads with — it is what the mechanism is for, not an incidental benefit. Second, the credential is not something the user types and remembers: authentication reuses the device unlock factors, biometrics or a PIN, or else a separate physical security key. That gives three admissible forms of the same method, one of which is hardware the user carries rather than anything stored on the signing-in device.

The scope of the Google change as reported is the default, applied to all users — the default sign-in method, rather than the only one available.
