# Sennheiser Momentum True Wireless 3

The Sennheiser Momentum True Wireless 3 was available for $142, down from $280 — a $138 saving and a new low; the pair has normally retailed around $180 in recent months.

This is the runner-up pick in Engadget's wireless earbuds guide, because Engadget's resident audio expert Billy Steele considers it the best-sounding true wireless pair he has tested.

That warm yet customizable sound is joined by a solid adaptive ANC system, though Sennheiser's pair is not as effective as the Sony WF-1000XM5 in that regard, nor does it have the same deep feature set.
