# Caesars Sportsbook Promo Code NEWS1000

Caesars Sportsbook promo code NEWS1000 gives new users a First Bet of up to $1,000 on Caesars, offered by Sporting News on Nov. 29, 2023 for the Volunteers vs. Tar Heels college basketball matchup.

The mechanics are a loss-refund rather than a bonus paid up front. A user starts by clicking the Caesars Sportsbook promo code link and signing up for a new account; if that first bet loses, Caesars credits the account with bonus bets in the amount of the wager, up to $1,000.
