# Unravel Two

Unravel Two casts players as Yarnys — living balls of yarn that look like small sprites — solving puzzles with a friend by using spare yarn to pull, yank, and swing. It appears in Polygon's 2023-10-20 list of the 35 best couch co-op games for Nintendo Switch.

The game requires quite a bit of teamwork.

What distinguishes it from other local co-op games is that where others might allow players to wander and do their own thing, this one is all about solving puzzles using each other's momentum.
