# K.O. II Pattern And Scene Structure And The Missing Song Mode

The K.O. II organises music in a hierarchy of groups, patterns and scenes but has no apparent song mode: there are four sample "groups" you can think of as tracks (drums, bass, lead and so on), each group can hold up to 99 patterns, patterns can be up to 99 bars long, and the active patterns across the four groups can be saved as a "scene."

Scenes can be triggered consecutively, but — importantly — there is no way for that to happen automatically right now. The consequence is that if you want to tease a whole recorded song out of the K.O. II, you have to either get clever with MIDI or trigger scenes and patterns manually in real time.
