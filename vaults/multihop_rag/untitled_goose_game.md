# Untitled Goose Game

Untitled Goose Game opens on a lovely morning in the village in which you are a horrible goose, and Polygon invites players to cause mayhem and honk to their heart's content in this charming game. It appears in the outlet's 2023-10-20 list of the 35 best couch co-op games for Nintendo Switch.

With local co-op, you and one friend can each be horrible geese.

The mode turns the mischief cooperative: the two geese use teamwork to terrorize the townspeople.
