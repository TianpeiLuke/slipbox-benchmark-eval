# System Shock (Nightdive Remake)

Nightdive Studios' System Shock remake, for Windows PC, is ranked 33 on Polygon's best video games of 2023 list of 2023-10-31. Polygon's point is that in a year of several stellar remakes and immersive sims it would not have been surprising if a nearly 30-year-old game showed its age, or if the changes needed to update it left it nigh unrecognizable — which is why Nightdive's accomplishment is so impressive: it updated the 1994 classic with a slick coat of modern paint while preserving what made the game thrilling in the first place.

That is most evident in the look, which captures all of the original's garish cyberpunk neons and frightening enemies in a style that appears like a modern high-fidelity game at a distance but subtly transforms into retro pixel bitmaps on closer inspection.

Critic CA extends the same observation to the gameplay: it feels surprisingly modern at a distance, but on closer inspection you start to see how this proto-immersive sim is actually what inspired so much modern game design. Players must rely on their own curiosity, caution, and cunning to navigate the halls of Citadel Station and upgrade their hacker into a cybernetic death machine — a game that expects a lot from the player, and a little save scumming, but is just as rewarding as it was in 1994.
