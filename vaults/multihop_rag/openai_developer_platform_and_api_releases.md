# OpenAI Developer Platform And API Releases

OpenAI progressively opened its models to developers through paid APIs and fine-tuning programmes, beginning with a paid API for ChatGPT — a move toward monetization whose initial customers included Instacart, Snap (Snapchat's parent company) and Quizlet.

Model access followed. OpenAI announced the general availability of GPT-4: starting July 6, all existing OpenAI developers "with a history of successful payments" could access GPT-4, with access planned for new developers by the end of July. OpenAI said it would in future allow developers to fine-tune GPT-4 and GPT-3.5 Turbo — one of the original models powering ChatGPT — with their own data, as had long been possible with several of OpenAI's other text-generating models, and that the capability should arrive later that year. It then brought fine-tuning to GPT-3.5 Turbo: companies using the model through the API can make it better follow specific instructions, such as always responding in a given language, improve its ability to consistently format responses, and hone the "feel" of its output, such as tone, so it better fits a brand or voice; most notably, fine-tuning lets customers shorten text prompts to speed up API calls and cut costs. OpenAI partnered with Scale AI to allow companies to fine-tune GPT-3.5, though it was unclear whether OpenAI was developing an in-house tuning tool to complement platforms like Scale AI or to serve a different purpose. Fine-tuning costs were $0.008 per 1K tokens for training, $0.012 per 1K tokens for usage input and $0.016 per 1K tokens for usage output. A GPT-4 fine-tuning programme followed, but unlike the GPT-3.5 programme it involves more oversight and guidance from OpenAI teams, largely because of technical hurdles.

OpenAI also extended the platform beyond text. DALL-E 3, its text-to-image model, became available via an API after first coming to ChatGPT-4 and Bing Chat, and OpenAI released a text-to-speech API, the Audio API, offering six preset voices and two generative AI model variants.
