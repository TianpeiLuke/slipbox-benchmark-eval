# The CPPA's ADMT Rulemaking Timeline

The draft proposal marks the start of the CPPA's rulemaking process, with a consultation process — which will include a public component — set to kick off in the weeks after November 27, 2023. So it is still a ways off a final text. A spokeswoman for the CPPA said it was unable to comment on a possible timeline for the rulemaking, but noted this is something that will be discussed at the upcoming board meeting on December 8.

If the Agency is able to move quickly, TechCrunch judges it possible it could have a regulation finalized in the second half of 2024. There would obviously need to be a grace period before compliance kicks in for in-scope companies, so 2025 looks like the very earliest for a law to be up and running — and who knows how far developments in AI will have moved on by then.
