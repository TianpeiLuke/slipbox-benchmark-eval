# Beeper's Open Source Transparency Effort

Beeper is hoping to gain trust by building in public, with 50-plus projects published to GitHub containing the open source code that goes into the app.

The company's second trust argument is about who is behind it: the founders themselves are known individuals with a history of building promising tech, including the Pebble smartwatch.
