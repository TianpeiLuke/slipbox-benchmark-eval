# Engadget's VPN Testing Methodology

To test the security specs of different VPNs and name its top picks, Engadget relied on pre-existing academic work through Consumer Reports, VPNalyzer and other sources, referenced privacy policies, transparency reports and security audits made available to the public, and considered past security incidents like data breaches.

The comparison criteria were price, usage limits, effects on internet speed, possible use cases, ease of use, general functionality and additional "extra" VPN features like multihop. The VPNs were tested across iOS, Android and Mac devices to see the state of the mobile apps across various platforms — Windows devices are also supported in most cases. Testers used the "quick connect" feature on each app to connect to the "fastest" provider available when testing internet speed, access to IP address data, and DNS and WebRTC leaks, which occur when a fault in the encrypted tunnel reveals requests to an ISP.

Three practical tests followed: a geoblocking test accessing Canada-exclusive Netflix releases, a streaming test watching a news livestream on YouTube via a Hong Kong-based VPN, and a gaming test playing on servers in the United Kingdom. Performing these tests at the same time also allowed the reviewers to test claims about simultaneous device use.
