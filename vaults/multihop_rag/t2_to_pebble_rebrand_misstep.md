# The T2 To Pebble Rebrand Misstep

Cselle questions in retrospect whether the rebranding from T2 to Pebble may have been an issue — an objection to the premise that the new name improved the product's positioning.

His reason is that the old name carried the value proposition directly: "I'm wondering if the Pebble rebrand had actually softened the value prop[position] because T2 just encapsulated it so much — that it was really duplicative [of Twitter]."
