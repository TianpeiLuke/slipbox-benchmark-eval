# Claiming BetMGM's $1,500 First Bet Offer With Bonus Code SPORTSPICK

BetMGM bonus code SPORTSPICK gave new customers a first bet offer worth up to $1,500 in bonus bets for the Eagles vs. Seahawks Monday Night Football game, per Sporting News on Dec. 18, 2023.

The steps are: use the exclusive BetMGM bonus code SPORTSPICK to register a new account; then make an initial deposit of at least $10; then bet on any game. If that first bet loses, BetMGM will return the full stake of that wager — up to $1,500 — as bonus bets.

The precondition is that the offer applies to new customers who use the promo code at registration, and the payout is contingent on the first bet losing.
