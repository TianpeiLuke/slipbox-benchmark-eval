# TikTok Pixel Pre-Consent Data Collection Test

Testing by The Age found that personal information typed into Australian websites was sent back to TikTok often before the user clicked "I consent" to the website's privacy policy.

The test was run by installing a browser extension and then visiting websites such as Sportsbet, Kmart, Beyond Blue and many others. On each site the testers went to sign up for an account, entering personal information including their full name, email address and phone number. Using Omnibug, they could see in real time that information being sent back to TikTok — and, crucially, that this often happened before consent to the site's privacy policy had been given.

The mechanism named in the report is a TikTok tool called "automatic advanced matching," which sees when a user enters text into a form field or a search box and, if it looks like an email address or phone number, scrapes that data.
