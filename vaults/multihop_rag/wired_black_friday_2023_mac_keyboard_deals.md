# WIRED Black Friday 2023 Mac Keyboard Deals

WIRED's Apple Black Friday guide of 25 November 2023 listed five discounted Mac keyboards: its favourite external keyboard from the Best MacBook Accessories guide, that guide's runner-up, the Das Keyboard MacTigr, a reviews editor's personal daily driver and a low-profile K3 Pro.

WIRED's favourite external keyboard is aimed at people who like the Magic Keyboard on their MacBook and want to fully replicate that setup; it includes a Touch ID button for logging in, authenticating purchases and downloading apps, and carries the same function row keys as the M-series MacBooks, including playback buttons, a Mission Control key and a dedicated Do Not Disturb button. The runner-up in the same guide also mimics the MacBook keyboard with a Do Not Disturb key and lets you program the function row with Apple's own apps such as Final Cut Pro, Photos and Safari through the Logi Options+ app, alongside other Mac-specific shortcuts; its stated limitation is that it comes only with Tactile Quiet switches, which WIRED says are ideal if you work around other people.

The Das Keyboard MacTigr (9/10, WIRED Recommends) is expensive, but WIRED calls it great for people in the Apple ecosystem thanks to its dedicated Mac layout, Cherry MX Red switches that do not get too loud, a two-port USB-C hub and a high-quality all-metal build. The fourth keyboard is WIRED reviews editor Julian Chokkattu's current daily keyboard: it works wired or wirelessly over Bluetooth, comes in several colours and switch options, is RGB-backlit, has red switches that are not very loud but still clicky, includes a knob for volume control, and is hot-swappable so you can change switches whenever you like. For low-profile keys, WIRED calls the K3 Pro a solid choice, with tactile-click keys, RGB lighting, around four to five days of battery life, USB-C charging and support for Via if you want additional software customisation.
