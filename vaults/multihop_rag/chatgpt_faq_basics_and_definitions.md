# ChatGPT FAQ: Basics And Definitions

ChatGPT is a general-purpose chatbot developed by tech startup OpenAI that uses artificial intelligence to generate text after a user enters a prompt; it runs on GPT-4, a large language model that uses deep learning to produce human-like text. GPT stands for Generative Pre-Trained Transformer.

The boundary against the wider category matters: a chatbot can be any software or system that holds dialogue with a person and does not necessarily have to be AI-powered — there are rules-based chatbots that give canned responses to questions — whereas ChatGPT is AI-powered and uses LLM technology to generate text after a prompt. ChatGPT was released for public use on November 30, 2022. Both the free version of ChatGPT and the paid ChatGPT Plus are regularly updated with new GPT models, and the most recent model is GPT-4; the free version requires only a sign-in. There is a free ChatGPT app, at launch limited to U.S. iOS users, with OpenAI saying an Android version is "coming soon," and there is an API, released March 1, 2023.

Anyone can use ChatGPT, and more and more tech companies and search engines are using the chatbot to automate text or quickly answer user questions and concerns. Multiple enterprises use it, although others limit use of the tool. Microsoft announced at its 2023 Build conference that it is integrating its ChatGPT-based Bing experience into Windows 11; the Brooklyn-based 3D display startup Looking Glass uses ChatGPT to produce holograms you can communicate with; and the nonprofit organization Solana integrated the chatbot into its network with a ChatGPT plug-in geared toward end users to help onboard into the web3 space.
