# Enterprise Browser And Cloud Data Security As Categories

Talon and Dig sit in two newer areas of the security market, which is what would make them especially attractive to a larger acquirer — and TechCrunch understands there appeared to be others previously looking at both.

Dig's category is securing data in the cloud, working across fragmented data spread over multiple clouds. That taps into a growing area of the market, since cloud spend is one of the only other areas where budgets are not being curtailed; it is a very crowded field, but also a prime opportunity to emerge as a leader in matching solutions to how companies are actually working in the real world.

Talon's category is the enterprise browser — a platform for large organizations to operate all of their apps and services, built from the ground up with security in mind. It is still relatively new in the market but has already started to catch on big with customers and competitors, Island being another company in the same space. "They're creating a new category that has the potential of being bigger than endpoint security altogether," one source said. "They're reinventing the operating system."
