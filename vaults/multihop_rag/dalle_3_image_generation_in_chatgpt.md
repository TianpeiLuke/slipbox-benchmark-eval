# DALL-E 3 Image Generation In ChatGPT

OpenAI unveiled DALL-E 3, an upgraded text-to-image tool that uses ChatGPT to help fill in prompts, and then integrated it directly into ChatGPT.

Subscribers to OpenAI's premium ChatGPT plans — ChatGPT Plus and ChatGPT Enterprise — can type in a request for an image and hone it through conversations with the chatbot, receiving the results directly within the chat app. The integration means users do not have to think so carefully about their text prompts when asking DALL-E to create an image, and they can receive images as part of their text-based queries without having to switch between apps.
