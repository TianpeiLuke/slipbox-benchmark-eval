# Amazon's Greenfield And Brownfield Retrofit Capability

Told that Amazon's immense resources let it build factories from the ground up, Tye Brady agreed it was a good observation but corrected the implication that the company only builds new: "The Sequoia system that you see is actually built for the height of our prior Kiva pods. If we wanted to retrofit buildings, we have that capability."

He set out the consequence directly: Amazon can containerize a building to bring the safety and productivity benefits to existing sites, and can retrofit brownfields it has already built with the Sequoia system. "We have greenfield and brownfield. Not everything is a greenfield."
