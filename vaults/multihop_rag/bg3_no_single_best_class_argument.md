# There Is No Single Best Class In Baldur's Gate 3

Polygon argues that there is no single best class in Baldur's Gate 3 — "barrelmancer aside" — so the choice should be settled by how you want to play rather than by any ranking of raw power.

The grounds are twofold. First, the classes in Baldur's Gate 3, and in pen-and-paper D&D for that matter, are all fairly well-balanced. Second, the game gives you as many opportunities for creative problem solving as it does for punching, so a class that looks weak in a straight fight still has routes to succeed. The warrant joining grounds to claim is that when options are balanced and the game rewards more than one kind of solution, "best" collapses into "best for your intended playstyle." A further supporting point removes the risk of a bad commitment: even when playing solo you still manage the rest of your party, so you get to experiment with multiple classes at once rather than being locked into one. Polygon repeats the same argument verbatim in its Warlock build guide of 2023-12-01, so the position is stated across both articles.
