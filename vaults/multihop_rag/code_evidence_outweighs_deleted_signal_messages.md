# Code Evidence Outweighs Deleted Signal Messages

The Verge's reporter argued after Gary Wang's October 6th, 2023 testimony that Bankman-Fried's vanishing Signal messages might not help him as much as he had hoped, because the durable evidence was the code — and the code implicates him even without the messages. The grounds: Wang's account was the first full account of Alameda's and FTX's entanglements heard in the trial, and it came from a co-owner of both companies; while there was evidence of the computer code that gave Alameda special privileges, there was no evidence of the conversations Wang recounted.

The warrant is that the code constrains who could have made the decisions. Wang was a dev; the money was not his area. And while Bankman-Fried can try to blame Ellison for some of the decisions, the code shows she could not have made all the calls — after all, she was not FTX's CEO, and in 2019 she was not Alameda's CEO either. Bankman-Fried also said too many things in public to too many people, so even without the smoking gun of Signal messages, it is hard to see how he was not involved.

The same logic explains Wang's own behaviour: of course he turned himself in quickly, because sooner or later someone would find his code — and Singh's, too.
