# The Objection To Moving An Unmet Inflation Target

Bundesbank President Joachim Nagel rejects the premise that a target can legitimately be revised while it is still being missed: "It would be a mistake of the first order to think you can change a goal you have set if you can't achieve it."

The objection is directed at the inference from difficulty to revision — that persistent failure to hit 2% is a reason to move the target — rather than at whether a higher target would be desirable in the abstract.
