# Default Search Engine

## Definition

The default search engine is the search provider a device, browser, or platform is pre-configured to use unless a user actively changes the setting — the search box that runs when a person types a query without first choosing an alternative, such as Google on the iPhone's Safari address bar or Firefox's search bar.

## Context

The term is central to *US v. Google*, the DOJ's antitrust case, because default status is the mechanism through which Google secures the overwhelming share of search queries: the Information Services Agreement (ISA) between Apple and Google, in place since 2002/2003, makes Google the default on all Apple devices, and Google separately pays Samsung, Mozilla, and other partners for the same status.
Apple executive Eddy Cue testified that Apple's iPhone setup flow deliberately omits any search-engine choice screen, arguing that presenting users with unfamiliar alternatives would harm the setup experience, while conceding the ISA does not permit Apple to offer such a choice.
Google spent $26.3 billion in 2021 on default-placement deals across browsers, phones, and platforms — about $18 billion of that to Apple alone — a scale that the DOJ used to argue Google understands the mechanism's value: internal 2007 data showed users who set Google as their homepage searched 15% more, while switching away dropped searches 27%.
The Mozilla/Yahoo episode shows the same mechanism working in reverse: when Firefox switched its default from Google to Yahoo under a 2014 deal, Mozilla's CEO testified that user retention declined, illustrating how disruptive changing the default can be even when a paying competitor is involved.
Outside the antitrust trial, the term also frames ordinary consumer behavior: an investor in e-commerce search startup Deft described users' "natural behavior" as following the path of least resistance and just using the default search engine, meaning challenger search products must offer a high-value proposition to displace that inertia.

## Key Characteristics

- **Set by agreement, not by user choice** — default status on major platforms (Apple's Safari/iOS, Android OEMs, Firefox) is typically established through commercial deals (e.g., the Apple-Google ISA, Yahoo-Mozilla's $375M/year deal) rather than user selection at setup.
- **Backed by large recurring payments** — Google paid $26.3 billion in 2021 across partners to hold default placement, with roughly $18 billion of that going to Apple.
- **Technically reversible but rarely changed** — Apple and Google both argued switching is easy, but DuckDuckGo's CEO countered that it takes "too many steps" to switch, and Google's own 2005 complaint about Internet Explorer's defaults argued that "most end users do not change defaults," so default status functions as durable market power.
- **Distinct from pre-installation** — Google's separate push to get Chrome and Search merely pre-installed (not necessarily defaulted) on Android and iPhones shows default status is a stronger, more contested tier than simple presence on a device.
- **Drives user behavior even outside browsers** — the concept extends to any search product; consumers default to "the path of least resistance," which challenger search startups must specifically overcome.
