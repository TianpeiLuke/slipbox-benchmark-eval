# The ITC Patent System Is Working As Originally Intended

Andrei Iancu's verdict on the Apple Watch ban is that nothing has gone wrong: "The takeaway is that the system is working as originally intended."

The warrant he supplies is the obligation the system places on importers: "If Apple wants to have products imported into the US, it should make sure that it comes up with its original inventions and does not infringe on other people's patented technology." On that reading, the dramatic consequences for Apple are the system operating correctly rather than a malfunction to be fixed.
