# Claiming Caesars Sportsbook's $1,000 First Bet With Promo Code NEWS1000

Caesars Sportsbook promo code NEWS1000 offered a First Bet bonus of up to $1,000 — "$1,000 First Bet On Caesars" — for the Eagles vs. Seahawks Monday Night Football game, per Sporting News on Dec. 18, 2023.

The steps are: click the Caesars Sportsbook promo code link and sign up for a new Caesars account, being sure that promo code NEWS1000 is entered when prompted; then make your first deposit, with a $10 minimum; then place your first Caesars Sportsbook bet. If that bet loses, you get the amount of that wager, up to $1,000, back as a single bonus bet.

The preconditions are registering a new account with the code and meeting the $10 minimum deposit; the refund is a single bonus bet rather than a set of smaller ones, and it is triggered only by a losing first bet.
