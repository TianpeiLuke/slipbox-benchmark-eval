# Inco, Encrypted Ethereum Virtual Machine

Inco Network is a seed-stage encrypted Ethereum virtual machine (EVM) layer-1 protocol founded by Remi Gai, presented in Alliance DAO's All11 cohort on 2023-10-18, that aims to help decentralized applications (dApps) operate on-chain. Its defining technology is fully homomorphic encryption (FHE), which is jargon for encryption that allows computations to be performed on encrypted data without having to decrypt it, so confidentiality is maintained throughout the computation.

The practical consequence of FHE for Inco is that it helps users write private smart contracts and perform computations, with use cases spanning card games and private voting. Gai said during his demo day presentation that the network is live on DevNet, its developer network, with mainnet launching in 2024. Inco was raising a seed round at the time.
