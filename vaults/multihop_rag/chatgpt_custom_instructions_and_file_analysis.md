# ChatGPT Custom Instructions And File Analysis

OpenAI launched custom instructions for ChatGPT so users do not have to write the same instruction prompts to the chatbot every time they interact with it, and later extended the feature to all users, including those on the free tier.

The company said the feature lets a user "share anything you'd like ChatGPT to consider in its response." For example, a teacher can say they are teaching fourth-grade math, or a developer can specify the code language they prefer when asking for suggestions; a person can also specify their family size so the text-generating AI can give responses about meals, grocery and vacation planning accordingly. The extension to the free tier allows all users to add various preferences and requirements they want the chatbot to consider when responding.

Separately, ChatGPT began testing file upload and analysis. Subscribers to ChatGPT's Enterprise Plan reported new beta features including the ability to upload PDFs to analyze and ask questions about them directly. The same rollout also means users no longer have to manually select a mode such as DALL-E or browsing when using ChatGPT — instead they are automatically switched to models based on the prompt.
