# How Insomnia Outlives Its Trigger

Sleep therapist Dr Lindsay Browning describes insomnia as a two-stage condition in which the thing that starts it is not the thing that keeps it going. Like depression or anxiety, insomnia is often triggered by an event — anything from something as monumental as becoming a new parent to something as commonplace as jet lag can prompt a bout of sleeplessness.

The second stage is where the disorder becomes self-sustaining: insomnia can often remain long after the trigger has gone. "At this point, you're no longer worried about the traumatic incident; you're now worried about not being able to sleep," Browning explains. The worry about sleeplessness substitutes for the original cause and produces the sleeplessness it fears — what The Independent calls a self-fulfilling prophecy. The relation holds specifically for the post-trigger phase, which is why treating the original event is no longer the relevant target.
