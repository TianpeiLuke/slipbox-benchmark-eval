# Diablo 4 Barbarian Key Passive Build Archetypes

Barbarians are Diablo 4's only pure melee class, with the other classes having hybrid builds for multiple ranges, and Polygon's 2023-10-19 guide identifies four main ideas that all Barbarian builds stem from: Fury dumping, which was most popular in the game's pre-season; weapon swapping; Bleed; and Berserk.

Each archetype is anchored to a Key Passive. Fury dump builds use the Unbridled Rage Key Passive, which causes Fury spenders to cost double the Fury but deal more than double the damage, and obviously require very steady Fury generation since it is easy to starve yourself. Berserk builds use the Unconstrained Key Passive and are all about keeping the Barbarian in the Berserk stage at all times, which nets a hefty bonus — all Barbarian builds will likely use some skills that trigger Berserk, and Unconstrained just enhances the effect. Bleed builds use the Gushing Wounds Key Passive to create a critical strike heavy build that is great for whittling down groups of enemies with damage over time and explosions. Weapon swapping builds, which take advantage of the Walking Arsenal Key Passive, offer what is almost certainly the most unique playstyle for Barbarians: constantly swapping between skills and weapons to give yourself massive damage buffs.

The practical rule that follows is to have one of these Key Passives in mind when building and choose skills accordingly; skills that share certain aspects, like Bleed, are color-coded on the skill tree and can be found with the in-game search function. Other Barbarian builds let you take advantage of mechanics like Thorns or Shouts, but they still typically end with one of these Key Passives.
