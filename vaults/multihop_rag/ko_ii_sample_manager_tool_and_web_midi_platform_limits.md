# K.O. II Sample Manager Tool And Web MIDI Platform Limits

Teenage Engineering provides a very cute tool for managing K.O. II samples that works via desktop browser — and its availability is bounded by Web MIDI support: for the brave it also runs on an Android phone (Chrome, Brave and Opera should all work), but on iOS the same browsers can't access Web MIDI and therefore will not work.

Engadget noted one iOS boundary case: there is the iOS Web MIDI Browser, which crashed when the reviewer tried it with an iPhone, though it does connect, so mileage may vary. The K.O. II won't show up on a PC as either a drive or an audio interface, so the main uses for the USB port are power and sending/receiving MIDI. The reviewer also recommended reading the manual, if for no other reason than it's likely the prettiest one you'll use in a while.
