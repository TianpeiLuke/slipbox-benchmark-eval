# ChatGPT FAQ: Capabilities And Limits

ChatGPT can write essays, and its everyday uses include programming, scripts, email replies, listicles, blog ideas and summarization, while advanced uses include debugging code, programming languages, scientific concepts and complex problem solving.

Its coding ability has a stated boundary: how good it is depends on the nature of the program. ChatGPT can write workable Python code but cannot necessarily program an entire app's worth of code, because it lacks context awareness — the generated code is not always appropriate for the specific context in which it is being used. On length, no character limit is documented anywhere, but users have noted some character limitations after around 500 words.

On workflow and detection: OpenAI allows users to save chats in the ChatGPT interface, stored in the sidebar of the screen, with no built-in sharing features yet. Several marketplaces host and provide ChatGPT prompts, either free or for a nominal fee — PromptBase is one, ChatX another, and more launch every day. ChatGPT output can be detected only poorly: several tools claim to detect ChatGPT-generated text, but in TechCrunch's tests they are inconsistent at best.
