# TP-Link Deco EX75 Mesh Router Deal

TP-Link's Deco EX75 mesh router system with two beacons was $100 off and down to a record low of $200 for Black Friday 2023. This is Engadget's top pick for a Wi-Fi 6 mesh router system, and the two-pack should cover up to 5,500 square feet with stable connectivity.

When Engadget tested the three-pack, it was impressed by how well the system balances power with user friendliness: its network is reliable and fast, and its companion app is easy to use and clearly shows things like all of the devices connected to the network, current speeds and more.
