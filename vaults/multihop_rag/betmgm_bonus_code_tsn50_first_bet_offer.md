# BetMGM Bonus Code TSN50 First Bet Offer

BetMGM bonus code TSN50 unlocks up to $1,550 in bonus bets for new customers — a First Bet bonus of up to $1,500 plus a $50 bonus bet for customers in select states — promoted by Sporting News on Nov. 29, 2023 for the Blue Devils vs. Razorbacks college basketball game.

To claim it, a user clicks the BetMGM bonus code link and registers a new account with promo code TSN50. The offer requires a minimum $10 deposit, but a user can deposit up to the amount of their first bet, to $1,500, to maximize potential winnings. If that first bet on the app loses, BetMGM refunds the account with bonus bets in the amount of the original wager, up to $1,500.

The $50 add-on carries a state restriction: the extra $50 bonus bet offer is not available in Washington D.C., Kentucky, Mississippi, Nevada, New York, Puerto Rico and Ontario. Customers in those areas can instead use BetMGM bonus code SPORTSPICK for the $1,500 First Bet offer.
