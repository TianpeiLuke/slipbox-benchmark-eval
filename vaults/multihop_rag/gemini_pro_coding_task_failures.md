# Gemini Pro's Coding Task Failures

Google emphasized Gemini's enhanced coding skills in a briefing in the first week of December 2023, and posts on X suggest it may genuinely have improved in some areas — but it also appears that Gemini Pro struggles with basic coding functions in Python. TechCrunch collected several user reports from 6 and 7 December 2023.

Filip Piekniewski reported that Gemini-based Bard still could not write the intersection of two polygons, calling it one of those rare, relatively simple to express functions that was never implemented in Python and has no Stack Overflow post, and noting that all these models fail on it. Mohsen Azimi found Gemini Pro "pretty disappointing" for his example: he asked it to make an analog clock using HTML like one ChatGPT made, and while it could cite some code from GitHub, it was off by a few milliseconds.

Two head-to-head comparisons went the same way. Edison Ade created a Tic Tac Toe game with both ChatGPT and Bard running on Gemini Pro, and reported that ChatGPT wrote the code on the first try while Bard took three tries, concluding GPT-4 was still greater than Gemini Pro. N Kiran Kumar tested Bard with the Gemini Pro update and got no bugless snake game on the first try; after reporting the bug and asking for a fix, the model could not fix it, whereas the free version of ChatGPT 3.5 returned correct, bug-free code on the first attempt.
