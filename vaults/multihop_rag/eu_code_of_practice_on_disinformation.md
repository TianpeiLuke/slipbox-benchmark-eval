# The EU Code Of Practice On Disinformation

The EU's voluntary anti-disinformation Code of Practice, set up in 2018, has 44 signatories in all — covering not just major social media and search platforms such as Google, Meta, Microsoft and TikTok, but entities from across the ad industry and civil society organizations involved in fact-checking.

Although the Code is not legally binding, it is tied to hard law. Following efforts to beef up the anti-disinformation Code the previous year, the Commission made clear it would treat adherence to the Code as a favorable signal for compliance with the legal requirements hitting larger platforms under the Digital Services Act (DSA) — another major piece of pan-EU digital regulation that obliges so-called very-large-online-platforms (VLOPs) and search engines (VLOSEs) to assess and mitigate societal risks attached to their algorithms, such as disinformation. Values and transparency commissioner Vera Jourova set out that relationship: "The DSA is now binding, and all the VLOPs have to comply with it. The Code underpins the DSA, because our intention is to transform the Code of Practice into a Code of Conduct that can form part of a co-regulatory framework for addressing risks of disinformation." She also warned that "Upcoming national elections and the EU elections will be an important test for the Code that platforms signatories should not fail," adding that "Platforms will need to take their responsibility seriously, in particular in view of the DSA that requires them to mitigate the risks they pose for elections."

The Code operates through periodic transparency reporting. A second batch of reports by Code signatories, covering the January to June period, was published on the day of Jourova's speech; at the time of writing only a handful were available for download on the EU's Disinformation Code Transparency Center, including reports from Google, Meta, Microsoft and TikTok. The EU said these are the most extensive reports produced by signatories to the Code since it was set up.
