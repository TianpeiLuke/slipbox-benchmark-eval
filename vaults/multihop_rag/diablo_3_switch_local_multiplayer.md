# Diablo 3 (Switch Local Multiplayer)

Now more than a decade old, Diablo 3 is still a great local multiplayer choice, especially on the Switch, according to Polygon's 2023-10-20 list of the 35 best couch co-op games for Nintendo Switch.

The action RPG felt bombastic when it first came out but has become a very comforting grind game to share with friends.

Polygon's writer adds a reason the older game still matters on that platform: Diablo 4 has not made its way to Nintendo Switch.
