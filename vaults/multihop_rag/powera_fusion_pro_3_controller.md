# PowerA Fusion Pro 3 Controller

The PowerA Fusion Pro 3 is the pick for people with Elite controller tastes but a standard controller budget — a fine alternative if you do not mind that it is wired. It looks a bit like the Microsoft Elite Series 2, complete with four rear buttons, trigger lockouts, and rubberized grips, but costs much less.

It is the latest version of PowerA's affordable alternative to premium controllers like the Xbox Elite Series 2, and comes with swappable sticks, friction rings, a compact zip-up case, and four programmable buttons built into its rear. Listed at $79 at Amazon and $80 at PowerA.

Against its predecessor it is significantly lighter, has a more compact case, and is $10 cheaper — quite the value for $79.99, especially if it starts going on sale. The older Fusion Pro 2 is still fine, especially if you prefer detachable rear paddles to built-in buttons, but at this point it is only worth it for that preference or if it is heavily discounted.
